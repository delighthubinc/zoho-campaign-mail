# HTML Preview QA Checklist

通常campaignでユーザーへHTML初稿・修正版を提示する前に確認する。

- [ ] campaign固有画像はすべてGitHub Pages正式URLを使用して表示される
- [ ] Google Drive直リンク / Base64埋め込みを暫定代替に使っていない
- [ ] セクション・カード・本文の意図しない重複がない
- [ ] メール全体が標準シェル幅内に収まり、途中から横幅が広がっていない
- [ ] 共通署名・ロゴ・宛名・注意書きが正式設定と一致する
- [ ] 件名 / preheader / CTAラベル / CTA URL / UTMが制作条件と一致する
- [ ] スマホ幅で明らかな横スクロール・カード崩れ・意図しないレイアウト変更がない

問題がある場合はユーザーへ提示する前に修正する。
